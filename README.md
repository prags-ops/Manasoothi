# 🌿 Manasoothi - Mental Health & Wellbeing Web Application

## 📌 Project Overview

Manasoothi is a full-stack mental health and wellness web application designed to help users monitor their emotional well-being, maintain personal journals, access wellness resources, and practice guided meditation. The application provides an intuitive user interface with secure backend APIs to manage user interactions efficiently.

The project demonstrates modern full-stack web development practices by integrating a responsive front-end with RESTful backend services, enabling dynamic data management and a seamless user experience.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/manasoothi.git
```

Move into the project directory

```bash
cd manasoothi
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Start the backend server

```bash
npm start
```

---

# 🔑 Environment Variables

Create a `.env` file in the root directory and configure the following variables.

```
GEMINI_API_KEY=GEMINI_API_KEY
PORT=3000
DATABASE_URL=your_database_url
```
